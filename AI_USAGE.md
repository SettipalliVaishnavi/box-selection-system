# AI Usage

## 1. Tools Used

I used ChatGPT and Claude as AI assistance tools during the development of this project.

- **ChatGPT:** Used for understanding technical concepts, debugging errors, getting suggestions, and improving parts of the implementation.
- **Claude:** Used for additional guidance, reviewing approaches, and understanding alternative solutions.

I personally worked on the majority of the project, including the application structure, implementation, business logic, frontend integration, and testing. AI tools were used only as supporting resources when I needed help.

## 2. Prompts I Gave

Some of the prompts I used during development included:

- Help me understand how to structure a Django project for this application.
- How can I implement box selection and packing logic in Python?
- Help me identify and fix errors in my Django application.
- Explain how to connect the frontend with Django API endpoints.
- How can I write test cases for the box selection and packing functionality?
- Review this code and suggest possible improvements.
- Help me understand edge cases in the packing algorithm.

These are representative examples of the types of prompts I used, rather than a complete verbatim history of every conversation.

## 3. Output I Accepted

I used some AI suggestions that helped me understand the implementation and improve the project.

I accepted useful explanations, debugging suggestions, code improvement ideas, and recommendations for handling edge cases.

I reviewed the suggestions before using them and made changes wherever necessary to match my project requirements. I did not blindly copy every AI-generated response.

## 4. Output I Rejected or Modified

Not every suggestion provided by AI tools was suitable for my project.

I modified suggestions when they did not match my existing code structure, requirements, or expected application behaviour.

I also made my own decisions about the implementation and adjusted the code based on my understanding and testing.

My main focus was to keep the application simple, functional, and maintainable.

## 5. Mistakes the AI Made

Some AI suggestions were not always compatible with my existing implementation. At times, suggested solutions needed additional modifications to work correctly.

I also noticed that AI-generated code could overlook certain edge cases or make assumptions about the project structure.

I checked the suggestions against my actual code, corrected issues where necessary, and tested the final implementation instead of assuming every suggestion was correct.

## 6. How I Verified the Final Code

I verified the project through code review and testing.

- Reviewed the main application logic and project structure.
- Checked the box selection and packing implementation.
- Ran the Django test suite using `python manage.py test`.
- Checked the test cases for different packing scenarios and edge cases.
- Reviewed the API functionality and expected responses.
- Checked the frontend and backend integration.

AI tools helped me during development, but I took responsibility for reviewing, modifying, and understanding the final implementation.

**Overall, this project was primarily developed by me, with ChatGPT and Claude serving as supporting tools for learning, debugging, and problem-solving.**
